# Job Portal Management System

## Project Overview

The **Job Portal Management System** is a database-driven application developed using **Python and MySQL**.

The system is designed to manage:

- Candidates
- Companies
- Jobs
- Job Applications
- Interviews
- Application Status
- Job Recommendations
- Reports

The project demonstrates important **SQL concepts, Python programming concepts, database connectivity, CRUD operations, transactions, views, subqueries, joins, aggregation, and file handling**.

---

# Technologies Used

- Python 3
- MySQL 8.0+
- MySQL Connector/Python
- SQL
- File Handling
- Object-oriented database concepts
